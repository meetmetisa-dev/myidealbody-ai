# Security policy

MyIdealBody AI is a development prototype, not a production health service. Do not deploy it with real user data, enable purchases, or rely on its nutrition output until the production controls in `docs/PRIVACY_SECURITY.md` and `docs/PLAY_STORE_LAUNCH.md` are completed and reviewed.

## Reporting a vulnerability

Please use GitHub's private **Security → Report a vulnerability** flow for this repository. If private reporting is unavailable, contact the repository owner through the [meetmetisa-dev GitHub profile](https://github.com/meetmetisa-dev) without including exploit details or personal data in a public issue.

Include the affected component, reproduction steps, likely impact, and a safe way to confirm the fix. Do not test against systems or accounts you do not own or have permission to assess.

## Supported versions

Only the latest commit on the default branch is considered for security fixes during the prototype stage. There is no production support or security SLA yet.
