Beta support

Use these public routes for non-sensitive questions and reproducible beta issues.

Choose the right route

Report a beta issue → Public GitHub issue · non-sensitive details only Read the project guide → Setup, Android build, API, and release documentation Report a security concern → Follow the repository's private-reporting instructions Read the Privacy Policy → Current website and Android beta data handling

This is community-style support for unfinished beta software. No service-level or response-time commitment is offered.

Before opening an issue

  1. Check the repository README and existing issues for the same problem.
  2. State whether the problem is on the website or Android beta, and include the browser or Android version.
  3. List short steps to reproduce, what you expected, and what actually happened.
  4. Share only synthetic or redacted examples. Do not upload a real meal photo if it contains people, documents, locations, health data, or other personal information.

Common beta questions

Did the public website analyze my photo?

No. The current GitHub Pages deployment has no production API configured. It previews the selected image in your browser, while the calorie and protein range comes from the meal, portion, and oil/sauce selections you make.

Did Android DEMO_MODE upload my selected photo?

No. Under the current default DEMO_MODE, the selected photo stays on the device and the fixed sample result is generated entirely inside the app. No analysis network request is made, the result does not consume the scan allowance, and it cannot be saved to the diary. Do not enable a real-photo provider until its privacy, security, retention, and deletion review is complete.

How do I remove local beta data?

Use the app's clear-history control for saved meal entries. To remove all Android beta preferences and local entries, clear the app's storage in Android settings or uninstall it. Clear this site's data in your browser to remove the saved language preference.

Is the app available on Google Play?

Not yet. The repository is a development MVP. Production photo analysis, authenticated entitlement verification, store listing completion, policy review, testing, and Play Console release steps remain before publication.

Privacy and account requests

The current beta has no account system and no server-side user profile to access or delete. Local Android data can be removed using the steps above. For a non-sensitive privacy question, use the contact route on the meetmetisa-dev GitHub profile. Never put personal or health information in a public issue.

Play release blockers

Do not make a public Play submission until the publisher has:

  • selected a monitored, private support/privacy email and added it to the Play Console listing, Data safety details, this page, and the Privacy Policy;
  • published the legal developer or publisher identity required for the store listing and policy.

GitHub issues alone are not an adequate private contact route for production users.

Dukungan beta

Gunakan jalur publik berikut untuk pertanyaan non-sensitif dan masalah beta yang dapat diulangi.

Pilih jalur yang tepat

Laporkan masalah beta → Issue GitHub publik · hanya informasi non-sensitif Baca panduan proyek → Dokumentasi setup, build Android, API, dan rilis Laporkan masalah keamanan → Ikuti petunjuk pelaporan privat pada repositori Baca Kebijakan Privasi → Penanganan data situs dan beta Android saat ini

Dukungan bergaya komunitas ini ditujukan untuk perangkat lunak beta yang belum selesai. Tidak ada jaminan waktu respons atau tingkat layanan.

Sebelum membuka issue

  1. Periksa README repositori dan issue yang sudah ada untuk masalah yang sama.
  2. Sebutkan apakah masalah terjadi pada situs atau beta Android, serta versi browser atau Android.
  3. Tuliskan langkah singkat untuk mengulangi masalah, hasil yang diharapkan, dan hasil yang terjadi.
  4. Bagikan hanya contoh sintetis atau yang telah disamarkan. Jangan unggah foto makanan nyata jika memuat orang, dokumen, lokasi, data kesehatan, atau informasi pribadi lain.

Pertanyaan umum beta

Apakah situs publik menganalisis foto saya?

Tidak. GitHub Pages saat ini belum memiliki API produksi. Situs hanya menampilkan pratinjau gambar di browser; rentang kalori dan protein berasal dari pilihan jenis makanan, porsi, serta minyak/saus yang kamu masukkan.

Apakah Android DEMO_MODE mengunggah foto pilihan saya?

Tidak. Dalam DEMO_MODE bawaan saat ini, foto pilihan tetap di perangkat dan contoh hasil tetap dibuat sepenuhnya di dalam aplikasi. Tidak ada permintaan jaringan untuk analisis, hasil tidak mengurangi batas pemindaian, dan tidak dapat disimpan ke catatan makanan. Jangan aktifkan penyedia foto nyata sebelum peninjauan privasi, keamanan, penyimpanan, dan penghapusan selesai.

Bagaimana menghapus data beta lokal?

Gunakan kontrol hapus riwayat di aplikasi untuk menghapus catatan makanan. Untuk menghapus seluruh preferensi dan catatan lokal beta Android, hapus penyimpanan aplikasi melalui pengaturan Android atau copot aplikasi. Hapus data situs pada browser untuk menghapus preferensi bahasa.

Apakah aplikasi tersedia di Google Play?

Belum. Repositori ini masih berupa MVP pengembangan. Analisis foto produksi, verifikasi hak akses terautentikasi, kelengkapan listing toko, peninjauan kebijakan, pengujian, dan langkah rilis Play Console harus diselesaikan sebelum publikasi.

Permintaan privasi dan akun

Beta saat ini tidak memiliki sistem akun atau profil pengguna di server yang dapat diakses atau dihapus. Data lokal Android dapat dihapus dengan langkah di atas. Untuk pertanyaan privasi non-sensitif, gunakan jalur kontak pada profil GitHub meetmetisa-dev. Jangan menuliskan informasi pribadi atau kesehatan pada issue publik.

Penghambat rilis Play

Jangan mengajukan rilis Play publik sebelum penerbit:

  • memilih email dukungan/privasi privat yang dipantau dan menambahkannya pada listing Play Console, informasi Keamanan data, halaman ini, serta Kebijakan Privasi;
  • mempublikasikan identitas pengembang atau penerbit legal yang diperlukan untuk listing toko dan kebijakan.

Issue GitHub saja bukan jalur kontak privat yang memadai untuk pengguna produksi.
